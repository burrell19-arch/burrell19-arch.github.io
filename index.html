Naruto Playlist Organizer

A personal application for managing YouTube playlists on Lillith Archives.

The organizer reads the channel’s existing playlists, creates approved playlists, and adds videos from a curated roster. It checks the authenticated channel before every write and permits changes only on Lillith Archives.

Why the app requests Google access

The owner authorizes access through Google. The read-only audit grant lists channel and playlist information. The separate writer grant lets the organizer make approved playlist changes through the YouTube Data API. This site provides information about the application and has no sign-in form.

The application is operated for the channel owner’s use. See how it handles data in the Privacy Policy and how it may be used in the Terms of Service.
